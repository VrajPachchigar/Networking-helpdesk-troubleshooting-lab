# Networking Help Desk Troubleshooting Lab

A home lab where I created, troubleshot, and closed real networking support tickets in **Spiceworks**, documenting each step and keeping screenshots as evidence.

## Skills Demonstrated
- Ticket creation, documentation, and closure in a help desk system (Spiceworks)
- Windows network troubleshooting with `ping`, `ipconfig`, `ipconfig /all`, `/release`, `/renew`, `/flushdns`
- Wi-Fi and Ethernet connectivity diagnosis
- DHCP and DNS troubleshooting
- Network adapter management (Device Manager, network reset)
- Basic performance troubleshooting (Task Manager, speed test)
