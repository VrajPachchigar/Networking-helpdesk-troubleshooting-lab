# Ticket 03: Ethernet Connected but No Internet

**Platform:** Spiceworks Help Desk  |  **OS:** Windows  |  **Status:** Resolved and closed

## Issue
Ethernet shows connected but there is no internet access.

## Troubleshooting Steps
1. Checked the physical Ethernet cable for broken pins or other cable issues
2. Used `ipconfig` to check the IP configuration
3. Disabled and re-enabled the Ethernet adapter in Device Manager
4. Pinged the default gateway
5. Used `ipconfig /flushdns` to refresh the DNS resolver cache

## Resolution
User's internet was up and running. Ticket closed in Spiceworks with troubleshooting notes.
