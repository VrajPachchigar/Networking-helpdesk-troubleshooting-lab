# Ticket 02: Wi-Fi Connected but No Internet

**Platform:** Spiceworks Help Desk  |  **OS:** Windows  |  **Status:** Resolved and closed

## Issue
Device shows connected to Wi-Fi but cannot reach the internet.

## Troubleshooting Steps
1. Checked the IP configuration using `ipconfig`
2. Used `ping` to check internet connectivity
3. Used `ipconfig /flushdns` to flush the DNS resolver cache
4. Changed the DNS server address to Google's DNS
5. Toggled the network adapter off and back on

## Resolution
User's internet was back on. Ticket closed in Spiceworks with troubleshooting notes.
