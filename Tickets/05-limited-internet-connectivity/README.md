# Ticket 05: Limited Internet Connectivity

**Platform:** Spiceworks Help Desk  |  **OS:** Windows  |  **Status:** Resolved and closed

## Issue
Device reports limited connectivity.

## Troubleshooting Steps
1. Toggled Wi-Fi off and on in Windows Settings
2. Checked that Airplane mode was off
3. Checked the IP address using `ipconfig`
4. Used `ipconfig /release` and `ipconfig /renew` to renew the IP address
5. Used `ping` to test internet connectivity
6. Rebooted the computer and checked that connectivity returned

## Resolution
Internet connectivity was restored. Ticket closed in Spiceworks with troubleshooting notes.
